# Below the Keep

Below the Keep is a roguelike for the terminal of macOS. It is written in Go, with the standard library alone.

## The game

One hero goes down into the dungeon below a ruined keep. An artifact waits on the fifth floor, at the bottom. Each move takes one turn. The hero gets stronger from items and from levels. When the hero dies, the run ends.

## The status

No playable version exists yet. [`docs/roadmap.md`](docs/roadmap.md) shows each gate and its status.

## How the project works

The owner writes all of the code and all of the tests. An agent plans the gates, answers questions, and reviews the code. [`AGENTS.md`](AGENTS.md) holds the rules of the agent. [`docs/decisions.md`](docs/decisions.md) holds each decision.
