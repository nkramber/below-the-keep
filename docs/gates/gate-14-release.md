# Gate 14: the balance and the release

## Goal

The owner plays full runs, and the numbers of the game get tuned. The README gets the instructions to play. Then the owner makes the first release.

## Scope

In:

- Play tests with different seeds.
- The tune of the numbers of P-5 to P-17. Each change needs an owner decision.
- A part "How to play" in `README.md`: the install, the minimum window, and the keys. The agent writes it (D-65).
- The first release. The owner does each git and GitHub step (D-12).

Out:

- Each part of section 13 of `docs/game-design.md`, for example a save.

## Success criteria

The first session of this gate reviews these criteria with the owner.

- [ ] The owner played 5 full runs with different seeds. The gate file records the seed and the result of each run.
- [ ] Each changed number has a row in `docs/decisions.md`, and `docs/game-design.md` shows the new number.
- [ ] `README.md` has a part "How to play" with the install, the minimum window, and the keys.
- [ ] `docs/open-questions.md` has no question that this release needs.
- [ ] The owner made the first release on GitHub.
- [ ] The owner ran the five checks of hard rule 5, and the output shows no failure.
